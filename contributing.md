## Contribution guide

* Code contributions to help improve Luster are very appreciated. However, I currently won't accept PRs for major features or large stylistic changes. For those, I generally prefer that people fork the project.
* **Please** ask me before starting work on a larger PR.

  * This helps avoid situations where you spend a lot of time developing something that I ultimately decide not to merge.
  * I may reject a larger change simply because I want to develop that part of Luster myself or have a different direction in mind.
  * Smaller contributions such as bug fixes, optimizations, translations, and fixes to existing systems are much more likely to be accepted.
* Use the project's GitHub issues or my discord server to talk about potential or ongoing development.
* Please be aware that I may sometimes go long periods without actively working on Luster, so it can take a while for me to review a pull request.
* Please follow [Style Guide](https://github.com/FourthEcho/Luster/blob/main/docs/style_guide.md)
