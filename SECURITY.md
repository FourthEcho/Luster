# Security Policy

## Supported Versions

Security fixes are made against the current maintained release and the actively maintained development branch.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature when available. Include:

- A clear description of the vulnerability.
- Steps to reproduce it.
- The affected version, branch, or commit.
- Any relevant logs, screenshots, or proof of concept.
- The potential impact.

Please allow reasonable time for investigation and remediation before public disclosure.

## Scope

Security reports should focus on vulnerabilities in the Luster repository, its build/release automation, or distributed shaderpack assets. Routine shader visual bugs and compatibility issues should be reported through the normal issue tracker.
