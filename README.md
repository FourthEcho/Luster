#### Frequently asked questions

1. "When will Luster be released for *new Minecraft version*?"

   * Shader packs are generally not very dependent on Minecraft versions; as long as Iris is available for that version, Luster should generally work.

2. "What shader loader does Luster support?"

   * Luster is designed for [Iris](https://irisshaders.dev/). OptiFine is not supported.

## Features

* Fully revamped sky, weather, water, and lighting
* Detailed clouds with multiple different types and layers
* Immersive weather providing different skies each day
* Screen-space path tracing
* Soft shadows with variable-size penumbras
* Detailed ambient occlusion (GTAO)
* Full labPBR material support
* screen-space reflections
* Volumetric fog
* Improved image quality TAA, FXAA, and CAS
* Advanced temporal upscaling with TAAU
* ACES tonemapping
* Camera effects: bloom, depth of field, motion blur, lens flare, vignette
* Advanced Global and Local exposure
* Low, Medium, High, Ultra profiles
